Bitácora del curso

Un resumen de cada etapa: qué vimos, qué hice y qué cambiaría si lo tuviera que hacer de nuevo hoy.

Junio 2022

Las primeras etiquetas

Arranqué con HTML puro: títulos, párrafos, listas, imágenes, tablas y enlaces. Lo más grande de esta etapa fue la página del portón automático, donde mezclé lo que sabía de Arduino con lo que estaba aprendiendo de HTML.

Junio 2022

Primeros estilos y formularios

Con la práctica de Valorant empecé a separar el contenido del diseño con una hoja de estilos aparte, a usar clases y a armar formularios de registro e inicio de sesión.

Mayo y junio 2023

Maquetado en serio

Retomé el curso y aparecieron position, Flexbox y las media queries. El listado de compras fue el primer sitio que usé para algo real: comprar los materiales del TP de Electrónica.

Junio a octubre 2023

Efectos y Bootstrap

En la galería de Funkos jugué con filtros, degradados y hover. Después vino Bootstrap y me di cuenta de que no hace falta escribir todo el CSS a mano para tener una navbar que ande en el celular.

2025

Un proyecto propio

La tienda de ropa es en lo que estoy ahora: Bootstrap descargado, un login y la idea de sumar el catálogo de productos. Esta página también la rehice con Bootstrap.

Lo que haría distinto hoy

Rutas relativas

Usaba rutas que empezaban con "/" porque andaban en Live Server, pero se rompen cuando subís el sitio a una subcarpeta. 

<!-- antes -->
<link href="/css/style.css">
<!-- ahora -->
<link href="../css/style.css">

Un id para cada input

Repetía el mismo id en varios campos. Cada id tiene que ser único para que el label funcione. 

<label for="email2">Repetí el email</label>
<input type="email" id="email2">

El alt de las imágenes

Muchas imágenes tenían el alt vacío o con el nombre del archivo. Tiene que describir la imagen para el que no la puede ver. 

<img src="groot.jpg"
     alt="Funko Pop de Groot">
