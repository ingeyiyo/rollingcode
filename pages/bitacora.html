Bitácora del curso

Cómo fui avanzando

Un resumen de cada etapa: qué vimos, qué hice y qué cambiaría si lo tuviera que hacer de nuevo hoy.

  1. Junio 2022

    Las primeras etiquetas

    Arranqué con HTML puro: títulos, párrafos, listas, imágenes, tablas y enlaces. Lo más grande de esta etapa fue el desafío del portón automático, donde mezclé lo que sabía de Arduino con lo que estaba aprendiendo de HTML.

  2. Junio 2022

    Primeros estilos y formularios

    Con la práctica de Valorant empecé a separar el contenido del diseño con una hoja de estilos externa, a usar clases y a armar formularios de registro e inicio de sesión.

  3. Mayo y junio 2023

    Maquetado en serio

    Retomé el curso y aparecieron position, Flexbox y las media queries. El listado de compras fue el primer sitio que usé para algo real: comprar los materiales del TP de Electrónica.

  4. Junio a octubre 2023

    Efectos visuales y Bootstrap

    En la galería de Funkos jugué con filtros, degradados y hover. Después vino Bootstrap: entender que no hace falta escribir todo el CSS a mano para tener una barra de navegación responsive.

  5. 2025

    Volver a encarar un proyecto propio

    La tienda de ropa es el proyecto en el que estoy ahora: Bootstrap con archivos locales, un login y la idea de sumar catálogo de productos.

Lo que haría distinto hoy

Rutas

Relativas, no absolutas

Usaba rutas que empezaban con "/" porque andaban en Live Server, pero se rompen al publicar el sitio en una subcarpeta. 

<!-- antes -->
<link href="/css/style.css">
<!-- ahora -->
<link href="../css/style.css">

Formularios

Cada label con su input

Repetía el mismo id en varios campos. Cada id tiene que ser único para que el label funcione y el formulario sea accesible. 

<label for="email2">Repetí el email</label>
<input type="email" id="email2">

Imágenes

Textos alternativos reales

Muchas imágenes tenían el alt vacío o con el nombre del archivo. El alt tiene que describir la imagen para quien no la ve. 

<img src="groot.jpg"
     alt="Funko Pop de Groot">
