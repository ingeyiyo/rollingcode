Position

Práctica de position en CSS

El recuadro punteado tiene position: relative, así las cajas de adentro se ubican tomándolo como referencia.

  • A tiene absolute y un z-index para quedar arriba de B.
  • B tiene absolute y se monta sobre A.
  • C tiene relative: se corre desde donde estaría normalmente.
  • El botón rojo de "Volver" de las páginas de componentes tiene fixed: queda siempre en el mismo lugar aunque bajes.
